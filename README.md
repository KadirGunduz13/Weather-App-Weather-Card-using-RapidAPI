# 🌤️ C# Weather App - Weather Card using RapidAPI

This project is a simple and functional **weather card** application developed with **C# Windows Forms**. It fetches real-time weather data such as temperature, wind speed, and humidity using the **OpenWeather API via RapidAPI** and displays it in a user-friendly interface.

## 🛠️ Technologies Used

- .NET Windows Forms (C#)
- REST API requests using HttpClient
- JSON data parsing with Newtonsoft.Json
- [RapidAPI - OpenWeather API](https://rapidapi.com/openweatherapi/api/open-weather13/)
